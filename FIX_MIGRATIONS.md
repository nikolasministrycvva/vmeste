# 🔧 Исправление проблемы с миграциями

## Проблема

В логах видно, что таблицы не существуют:
- `The table main.User does not exist`
- `The table main.WorkoutType does not exist`

Это означает, что **миграции не были применены** к базе данных.

## Решение

### Вариант 1: Применить миграции вручную через Vercel CLI (рекомендуется)

1. **Установите Vercel CLI** (если еще не установлен):
   ```bash
   npm install -g vercel
   ```

2. **Войдите в Vercel**:
   ```bash
   vercel login
   ```

3. **Подключите проект**:
   ```bash
   vercel link
   ```

4. **Скачайте переменные окружения**:
   ```bash
   vercel env pull .env.local
   ```

5. **Примените миграции**:
   ```bash
   npx prisma migrate deploy
   ```

6. **Заполните базу данных**:
   ```bash
   npx prisma db seed
   ```

### Вариант 2: Перезапустить деплой с правильными переменными

1. **Проверьте переменные окружения в Vercel**:
   - Откройте Vercel Dashboard
   - Ваш проект → Settings → Environment Variables
   - Убедитесь, что есть:
     - ✅ `POSTGRES_URL`
     - ✅ `POSTGRES_PRISMA_URL`
     - ✅ `POSTGRES_URL_NON_POOLING`
     - ✅ `POSTGRES_PASSWORD`
     - ✅ `DATABASE_URL` (должна быть равна `POSTGRES_URL_NON_POOLING`)

2. **Перезапустите деплой**:
   - Vercel Dashboard → Deployments
   - Найдите последний деплой
   - Нажмите на три точки (⋯) → **Redeploy**

3. **Проверьте логи деплоя**:
   - Должна быть строка: `Running "prisma migrate deploy"`
   - Если есть ошибки, проверьте переменные окружения

### Вариант 3: Создать API endpoint для миграций (временное решение)

Можно создать временный endpoint для применения миграций, но это не рекомендуется для продакшена.

## После применения миграций

1. **Заполните базу данных**:
   - Откройте в браузере: `https://your-project.vercel.app/api/seed`
   - Или выполните POST запрос к этому URL

2. **Проверьте результат**:
   - Обновите главную страницу
   - Должны появиться тестовые пользователи

## Проверка

После применения миграций проверьте:
- В логах деплоя должна быть строка об успешном применении миграций
- Таблицы должны быть созданы в базе данных
- Seed скрипт должен выполниться без ошибок
