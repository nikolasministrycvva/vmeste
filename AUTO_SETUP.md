# 🚀 Автоматическая настройка базы данных

## ✅ Теперь всё автоматически!

После подключения Supabase, вам нужно выполнить **только один шаг**:

### Откройте в браузере:

```
https://vmestevercel.vercel.app/api/setup-database
```

Этот endpoint автоматически:
1. ✅ Создаст все таблицы в базе данных
2. ✅ Заполнит базу данных тестовыми данными
3. ✅ Создаст пользователей (Admin, Client, Trainers)
4. ✅ Создаст типы тренировок

**Всё за один запрос!** 🎉

---

## Что будет создано автоматически:

- **1 администратор** (Admin)
- **1 клиент** (Client 1)
- **3 тренера** (Anna, Max, Olga)
- **3 типа тренировок** (Functional, Strength, Stretching)

---

## После выполнения

1. Обновите главную страницу
2. Должны появиться тестовые пользователи
3. Можно сразу начинать работать!

---

## Если нужно заполнить базу данных отдельно

Если таблицы уже созданы, но нужно только заполнить данные, используйте:

```
https://vmestevercel.vercel.app/api/seed
```

---

## Безопасность

⚠️ **Важно:** После настройки базы данных рекомендуется:
- Удалить endpoint `/api/setup-database` 
- Или защитить его паролем/секретным ключом

Это предотвратит случайное пересоздание таблиц в продакшене.
