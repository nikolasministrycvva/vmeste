# Vместе WebApp

Веб-приложение на Next.js 14 с App Router и TypeScript.

## Что такое Node.js и зачем он нужен?

**Node.js** — это программа, которая позволяет запускать JavaScript код на вашем компьютере (не только в браузере). Для работы с Next.js проектами Node.js необходим, потому что:

- Next.js написан на JavaScript и требует Node.js для работы
- Node.js включает в себя **npm** (Node Package Manager) — менеджер пакетов для установки библиотек и зависимостей проекта
- Node.js позволяет запускать сервер разработки на вашем компьютере

## Проверка установки Node.js

Перед началом работы убедитесь, что Node.js установлен на вашем компьютере:

1. Откройте **PowerShell** (нажмите `Win + X` и выберите "Windows PowerShell" или найдите в меню Пуск)
2. Введите команду:
   ```bash
   node --version
   ```
3. Если Node.js установлен, вы увидите номер версии (например, `v24.11.0`)
4. Также проверьте npm:
   ```bash
   npm --version
   ```
   Должна отобразиться версия npm (например, `11.6.1`)

### Если Node.js не установлен

1. Перейдите на официальный сайт: https://nodejs.org/
2. Скачайте **LTS версию** (рекомендуется для большинства пользователей)
3. Запустите установщик и следуйте инструкциям
4. После установки перезапустите PowerShell и проверьте установку командами выше

## Начало работы с проектом

### Шаг 1: Откройте терминал в папке проекта

1. Откройте PowerShell
2. Перейдите в папку проекта. Например, если проект находится на рабочем столе:
   ```bash
   cd "C:\Users\novel\OneDrive\Рабочий стол\Тренер V"
   ```
   Или просто перейдите в папку через Проводник, щелкните правой кнопкой мыши и выберите "Открыть в терминале" / "Open in Terminal"

### Шаг 2: Установите зависимости проекта

В терминале выполните команду:
```bash
npm install
```

**Что делает эта команда?**
- Читает файл `package.json`, где перечислены все необходимые библиотеки
- Скачивает и устанавливает все зависимости в папку `node_modules`
- Это может занять несколько минут при первом запуске

### Шаг 3: Запустите сервер разработки

После установки зависимостей выполните:
```bash
npm run dev
```

**Что происходит?**
- Запускается локальный веб-сервер на вашем компьютере
- Сервер будет доступен по адресу `http://localhost:3000`
- В терминале появится сообщение: `Ready - started server on 0.0.0.0:3000`

### Шаг 4: Откройте приложение в браузере

1. Откройте любой браузер (Chrome, Firefox, Edge и т.д.)
2. В адресной строке введите: `http://localhost:3000`
3. Нажмите Enter
4. Вы должны увидеть страницу с заголовком "Vместе" и текстом "Welcome to Vместе WebApp"

### Остановка сервера

Чтобы остановить сервер разработки, нажмите `Ctrl + C` в терминале.

## Основные команды и их объяснение

### `npm install`
**Что делает:** Устанавливает все библиотеки и зависимости, необходимые для проекта.
**Когда использовать:** Один раз при первом запуске проекта, или когда добавляются новые зависимости.
**Пример:**
```bash
npm install
```

### `npm run dev`
**Что делает:** Запускает сервер разработки. Позволяет видеть изменения в коде в реальном времени.
**Когда использовать:** Каждый раз, когда вы хотите запустить проект для разработки.
**Пример:**
```bash
npm run dev
```
После запуска откройте браузер и перейдите на `http://localhost:3000`

### `npm run build`
**Что делает:** Создает оптимизированную версию проекта для размещения на сервере (продакшен).
**Когда использовать:** Когда проект готов к публикации.
**Пример:**
```bash
npm run build
```

### `npm start`
**Что делает:** Запускает оптимизированную версию проекта (требует предварительного `npm run build`).
**Когда использовать:** Для тестирования продакшен версии локально.
**Пример:**
```bash
npm start
```

### `npm run lint`
**Что делает:** Проверяет код на наличие ошибок и предупреждений.
**Когда использовать:** Для проверки качества кода перед коммитом.
**Пример:**
```bash
npm run lint
```

## Что означают основные термины?

- **npm** (Node Package Manager) — менеджер пакетов, который устанавливает библиотеки для вашего проекта
- **node_modules** — папка, где хранятся все установленные библиотеки (не нужно редактировать вручную)
- **package.json** — файл со списком всех зависимостей проекта и скриптов
- **localhost:3000** — адрес локального сервера на вашем компьютере (3000 — это порт)
- **Терминал/Консоль/PowerShell** — программа для ввода текстовых команд

## Структура проекта

- `app/` - Директория App Router, содержащая страницы и макеты
  - `layout.tsx` - Корневой макет с заголовком
  - `page.tsx` - Главная страница
  - `globals.css` - Глобальные стили с Tailwind CSS
- `package.json` - Зависимости проекта и скрипты
- `tsconfig.json` - Конфигурация TypeScript
- `tailwind.config.ts` - Конфигурация Tailwind CSS
