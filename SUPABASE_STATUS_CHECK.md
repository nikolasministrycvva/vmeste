# Как проверить статус проекта и базы данных в Supabase

## Пошаговая инструкция

### Шаг 1: Войдите в Supabase Dashboard

1. Откройте браузер
2. Перейдите на https://supabase.com/dashboard
3. Войдите в свой аккаунт (если не вошли)

### Шаг 2: Найдите ваш проект

1. На главной странице Dashboard вы увидите список всех ваших проектов
2. Найдите проект с URL: `jpuysnakxddrctcerzhc` или похожим названием
3. Нажмите на проект, чтобы открыть его

### Шаг 3: Проверьте статус проекта

**Вариант A: На главной странице проекта**

1. После открытия проекта вы увидите обзор (Overview)
2. В верхней части страницы будет показан статус проекта:
   - 🟢 **Active** (Активен) - проект работает
   - 🟡 **Paused** (Приостановлен) - проект приостановлен
   - 🔴 **Inactive** (Неактивен) - проект неактивен

**Вариант B: В настройках проекта**

1. В левом меню нажмите на **Settings** (Настройки)
2. Выберите **General** (Общие)
3. Проверьте статус проекта в разделе "Project Status"

### Шаг 4: Проверьте статус базы данных

1. В левом меню нажмите на **Database** (База данных)
2. Или перейдите в **Settings** → **Database**
3. В верхней части страницы вы увидите:
   - Статус базы данных (Active/Paused)
   - Информацию о размере базы данных
   - Время последнего бэкапа

### Шаг 5: Если база данных приостановлена (Paused)

1. На странице Database или в Settings → Database
2. Найдите кнопку **"Resume"** или **"Start"** или **"Restore"**
3. Нажмите на неё, чтобы запустить базу данных
4. Подождите несколько минут, пока база данных запустится

### Шаг 6: Получите Connection String

1. Перейдите в **Settings** → **Database**
2. Прокрутите страницу вниз до раздела **"Connection string"**
3. Вы увидите несколько вкладок:
   - **URI** - для прямого подключения (используйте эту)
   - **Connection pooling** - для пула подключений
   - **JDBC** - для Java
   - **etc.**

4. Выберите вкладку **"URI"**
5. Вы увидите строку вида:
   ```
   postgresql://postgres:[YOUR-PASSWORD]@db.xxxxx.supabase.co:5432/postgres
   ```
6. Нажмите на кнопку **"Copy"** или скопируйте строку вручную
7. **Важно:** Если вы видите `[YOUR-PASSWORD]`, вам нужно:
   - Найти раздел "Database password" выше на странице
   - Если пароля нет, нажмите "Reset database password"
   - Скопируйте новый пароль
   - Замените `[YOUR-PASSWORD]` в connection string на реальный пароль

### Шаг 7: Обновите файл .env.local

1. Откройте файл `.env.local` в корне вашего проекта
2. Замените значение `DATABASE_URL` на скопированную строку:
   ```env
   DATABASE_URL="postgresql://postgres:ВАШ_ПАРОЛЬ@db.xxxxx.supabase.co:5432/postgres"
   ```
3. Сохраните файл

## Визуальные подсказки

### Где искать статус:

```
Supabase Dashboard
├── Projects (список проектов)
│   └── Ваш проект
│       ├── Overview (статус проекта)
│       ├── Database (статус базы данных)
│       └── Settings
│           ├── General (статус проекта)
│           └── Database (статус БД + Connection string)
```

### Что означают статусы:

- **Active** 🟢 - Всё работает, можно подключаться
- **Paused** 🟡 - База данных приостановлена, нужно запустить
- **Inactive** 🔴 - Проект неактивен, нужно активировать

## Частые проблемы

### Проблема: Не вижу кнопку "Resume"
**Решение:** 
- Убедитесь, что вы находитесь в разделе Database или Settings → Database
- Если кнопки нет, возможно база данных уже активна
- Или проект на бесплатном плане и был автоматически приостановлен

### Проблема: Не могу найти Connection string
**Решение:**
- Убедитесь, что вы в Settings → Database
- Прокрутите страницу вниз
- Connection string находится в разделе "Connection string" или "Connection info"

### Проблема: Вижу [YOUR-PASSWORD] в connection string
**Решение:**
- Найдите раздел "Database password" на той же странице
- Если пароля нет, нажмите "Reset database password"
- Скопируйте пароль и замените [YOUR-PASSWORD] в connection string
